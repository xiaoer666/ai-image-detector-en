## Recommended Workflow

1. Upload the original image whenever possible. Avoid screenshots, compression and social-media re-saves.
2. Review the AI-generation likelihood and confidence as a first screening signal.
3. If metadata, generator keywords, C2PA or content credential clues appear, investigate the image source.
4. For news, legal, commercial or high-stakes decisions, combine the result with source links, publication time, account history and reverse image search.
